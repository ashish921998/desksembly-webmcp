# Desksembly Demo Script

Target length: 90 seconds. Submission limit: under 3 minutes.

## 0–10 seconds — Orientation

Open Desksembly. Show the deterministic fallback banner, empty desk, locked
orange lamp, $350 US brief, and the Shopify plus five-desk-tool readiness badge.

Narration: “Desksembly gives a shopper and their browser agent one shared,
directly manipulable product world.”

## 10–30 seconds — Agent-built world

Show Shopify `search_catalog`, `deskbuilder.get_scene`, `preview_plan`, and
`stage_plan`. Watch four labeled parcels arrive one at a time and the activity
ribbon settle.

Narration: “Shopify owns commerce discovery. Desksembly's WebMCP tools own only
the versioned miniature scene.”

## 30–44 seconds — Human edit

Select the QuietType keyboard and lock it. Optionally drag the monitor to its
alternate valid anchor.

Narration: “The shopper can directly change or lock any decision. Every manual
edit advances the same scene version used by the agent.”

## 44–62 seconds — Constraint shock

Apply the 90 cm, $300, US-availability request. Briefly show the stale call
failure, then the refreshed revision. The plant returns; the felt coaster arrives;
the locked keyboard and unaffected IDs remain.

Narration: “The stale mutation is rejected. After refreshing, only the actual
conflict changes.”

## 62–78 seconds — Exact review

Prepare the exact deterministic review. Show product lines, variants, prices,
and total. Approve once; accepted-only cart receipts appear and the unrelated
headphone stand remains.

Narration: “Review approval is exact and one-time. Partial results stay partial.”

## 78–90 seconds — Honest handoff

Show the reconciled deterministic cart and disabled Shopify Checkout control.

Narration: “No participant development store is connected, so Desksembly never
pretends this is a real checkout. The native Shopify gate is proven separately,
and the fallback is labeled everywhere.”
